## Installer l'appli (téléphone, tablette ou ordinateur)

**Pas besoin de télécharger de fichiers** : ouvrez le lien ci-dessus, puis :

| Appareil | Comment faire |
|---|---|
| **Android** (Chrome) | Bouton orange **« 📲 Installer »** en bas à droite de l'écran d'accueil de l'appli, ou menu **⋮** → **Installer l'application** |
| **iPhone / iPad** (Safari) | Bouton **Partager** (carré avec une flèche) → **Sur l'écran d'accueil** → **Ajouter** |
| **PC / Mac** (Edge ou Chrome) | Bouton **« 📲 Installer »**, ou icône d'installation dans la barre d'adresse |

L'icône ChefAutonome (une poêle sur fond orange) apparaît alors sur l'écran d'accueil ou dans le menu Démarrer.
L'appli s'ouvre dans sa propre fenêtre, fonctionne sans connexion et se met à jour toute seule.

## Utilisation

- **Espace résident** (écran d'ouverture) : 🛒 **Au Magasin** pour cocher les courses, 🍳 **En Cuisine** pour choisir les aliments puis lancer des minuteurs visuels avec alarme.
- **⚙️ Configuration** (pour le professionnel) : temps de cuisson, photos personnelles, liste de courses, listes favorites, affichage des noms.

## Confidentialité

- Aucune donnée n'est envoyée sur Internet : aliments, photos, listes et réglages restent **dans l'appareil**.
- Aucun compte, aucune donnée nominative.
- Chaque appareil a ses propres réglages : il faut configurer l'appli sur chacun.
- Sur iPhone, l'appli installée a sa propre mémoire, séparée de Safari : installez-la avant de faire la configuration.
